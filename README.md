# Patient Dashboard

A simple bento-style web app that fetches and displays patient data from an API. Built with vanilla JavaScript and Chart.js to visualize patient health information.

## Features

- Displays patient profiles with images and basic info  
- Interactive search to filter patients by name  
- Shows lab results and diagnostic data in tables  
- Visualizes health history using line charts  
- Responsive bento-style layout

## Technologies Used

- Vanilla JavaScript  
- Fetch API for data retrieval  
- Chart.js for data visualization  
- HTML & CSS for layout and styling

## How to Use

1. Clone the repository  
2. Open `index.html` in your browser  
3. The app automatically fetches patient data and displays it  
4. Click on a patient to see detailed info and charts  
5. Use the search bar to filter patients by name
